# DART BIG:IN 프론트엔드 디자인 견본

기존 서비스와 분리된 임시 프론트엔드입니다. `dist/index.html`을 브라우저에서 열면 작동합니다. 별도 설치나 DB·LLM API 연결은 필요하지 않습니다.

모든 주가·지수·재무 수치·공시 발췌·인사이트는 가상 데이터입니다. 기업명은 화면 구성의 예시로 사용했습니다. 공시 각주의 원문도 실제 보고서 인용이 아닙니다.

- 첫 화면: 원형 섹터 탐색
- 산업 화면: 시장 추세, 워드 클라우드, 인사이트, 기업 카드, 재무 그래프, 기업 비교
- 기업 화면: 해당 산업 내 기업 전환과 개별 그래프
- 상호작용: 키워드 설명, 각주 원문 패널, 지표 도움말, 그래프 상세 수치와 예시 원문 표
- 모바일: 세로 배열, 가로 기업 카드, 하단에서 펼쳐지는 설명 패널
- 접근성: 키보드 탐색, 설명 창의 초점 관리, 움직임 감소 설정 대응

이 폴더를 삭제해도 기존 서비스의 코드와 분석 결과에는 영향이 없습니다. 견본을 계속 검토할 수 있도록 임시 결과물은 보존합니다.

폰트는 Pretendard를 사용합니다. `dist/fonts/`에 포함한 글꼴은 SIL Open Font License에 따라 배포되며, 라이선스는 같은 폴더에 보존했습니다.
