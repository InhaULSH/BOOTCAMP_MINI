## 1. H1 수정 전후 조회 결과

**원인:** 뷰가 `financial_facts.standard_account_nm`(저장된 표시명)을 24개 표준명과 정확히 일치로 조인했다. 그래서 같은 공식 태그가 "당기순이익(손실)", "영업이익(손실)", "영업활동으로 인한 현금흐름" 등으로 저장되면 빠졌다.

**수정(마이그레이션 006, 운영 MySQL 미적용)**
- **매칭 방식:** 공식 계정 ID와 표 구분(IS·CIS는 한 묶음)으로 매칭한다.
  - 태그는 기존 승인 매핑(`standard_account_mapping`)에서 가져왔다.
  - 영업이익 두 번째 태그로 `ifrs-full_ProfitLossFromOperatingActivities`를 추가했다.
- **태그가 없는 회사 고유 계정:** 저장된 표시명으로 대체 매칭한다. 이때 해당 표준계정의 재무제표 종류와 기간 성격이 맞을 때만 인정한다(잔액은 BS 시점값, 손익은 IS/CIS, 현금흐름은 CF).
- **슬롯당 1행:** 회사·기간·연결/별도·표준계정·값 구분마다 1행만 반환한다. 우선순위는 태그 → IS > CIS → API 직접값 → 표시 순서다.
- **검증 방법:** 같은 SELECT를 운영 MySQL에 **읽기 전용**으로 실행해 비교했다(DDL 미실행).

## 2. H3 수정 전후 조회 결과

- **기준 확인:** 에이치브이엠 사실값은 2024~2025 7개 기간 모두 OFS뿐이다(CAPEX 13행도 OFS). CFS는 없다.

| 에이치브이엠 AUTO 조회(2025 FY) | 0행 | 204행, 모든 기간 OFS 지정 조회와 동일 |

| 다른 24개사 AUTO 조회(일반·CAPEX, 전 기간) | – | 586개 슬롯 모두 동일 |
