아래는 폐기한 이전 버전의 구현 이력입니다. 과거 전용 코드·원본·가공·임베딩 자료는 삭제했습니다. 아래의 과거 data/Qdrant 및 계층형 요약 실행 명령은 더 이상 지원하지 않습니다. 현재 실행 방법은 위 안내를 따르세요.

# SnapDART REPORT 프로토타입

BOOTCAMP_MINI의 처리 결과를 읽는 로컬 화면입니다. 삼성전자·SK하이닉스·한미반도체·주성엔지니어링·원익IPS의 2023-2025년 보고서를 사용합니다.

## 실행

```powershell
cd C:\Users\LSH\Downloads\Code\BOOTCAMP_MINI_PROTO
python -X utf8 app.py
```

http://127.0.0.1:8501 에서 확인합니다. 화면 실행 시 시세만 외부에서 갱신하고 저장된 분석 보고서를 읽습니다. GPU·Qdrant·Gemini 분석은 실행하지 않습니다. 각주를 누르면 중앙 처리 폴더의 원문 문단도 읽습니다. 포트가 사용 중이면 `--port 8502`를 지정합니다.

## 데이터 연결

기본 입력 위치는 형제 폴더 `../BOOTCAMP_MINI`입니다. 다른 위치를 쓰면 실행 전에 `SNAPDART_PIPELINE_ROOT` 환경변수를 지정합니다. 원문·CSV·벡터를 프로토타입에 복사하거나 다시 청킹하지 않습니다.

| 입력 | 사용처 |
|---|---|
| `data/processed/source/documents.json` | 기업·연도·분기/반기/사업보고서와 원문 식별자 |
| `data/processed/retrieval/units.jsonl` | 본문 사업의 내용 문단·정성 표 행에서 주제별 문장 발췌 및 단어 횟수 집계 |
| `data/processed/retrieval/chunks.jsonl` | 선택 실행하는 LLM의 근거. 게시된 청크·문단 ID를 그대로 유지 |
| `data/processed/embeddings/manifest.json` | 데이터 해시·Qdrant 컬렉션 확인 |
| `data/opendart/*/financial_연도.json` | 계정 ID·재무제표 구분을 확인하여 연간 재무 계산 |
| `data/opendart/*/filings.json` | 비교표에 표시할 공시 목록 |

`numbers.csv`는 미검증 숫자 출현 목록이므로 매출·이익 계산에 사용하지 않습니다. LLM 분석 때는 검색된 원문 문단 ID로 연결되는 숫자 출현 기록을 청크당 최대 4개까지 함께 제공합니다. 원문에서 발견된 수치라는 상태를 유지하며 확정된 재무 계정으로 격상하지 않습니다. `table_cells.csv`와 원문 표는 추적용 자료로 중앙 파이프라인에 보존합니다. 보고서의 날짜는 해당 문서의 기간이며 수치의 의미를 임의로 확정하지 않습니다.

`snapdart/source_data.py`가 연결을 담당합니다. 읽어온 결과는 프로토타입의 `data/reports.json`으로 생성합니다.

```powershell
# 새 중앙 자료를 반영. 외부 API 호출 없이 재생성합니다.
python -X utf8 -m snapdart.analyze --offline
```

## 화면

- 최초 화면은 산업 노드이며 기업 화면은 산업 비교표/주가 카드에서 진입합니다. 기업 상세에서만 사이드바를 표시합니다.
- 상단은 KRX 반도체 지수와 주요 공시 신호 워드 클라우드입니다. 별도의 섹터 요약·최근 DART 공시 동향 문단은 통합했습니다.
- 워드 클라우드는 선택 연도의 사업·반기·분기보고서 본문 중 사업의 내용에 속한 선별 문단/정성 표 행에서 지정 사업 용어의 출현 횟수를 셉니다. 청킹 전 단위로 세므로 분할과 반복 제목의 영향은 없습니다. 다른 보고서에 반복된 문장은 각각 셉니다. 한국어는 부분문자열, 영문 약어는 영숫자 경계를 적용합니다. 동의어 통합·긍정/부정 판단·TF-IDF는 없습니다. 단어에 마우스를 올리면 횟수가 표시됩니다.
- 매출·영업이익·현금 유형자산 취득·영업현금흐름은 3개년 5개 기업의 전년 대비 변동률 꺾은선으로 표시합니다. 0% 기준선을 가운데 두어 증가와 감소를 구분합니다. 계산은 `(당년 값 - 전년 값) / 전년 값 × 100`입니다. 첫해는 동일 재무 JSON의 전기 금액을 이용합니다. 연도 선택 버튼은 제거했으며 요약·워드클라우드·인사이트·비교표는 최신 연도를 기준으로 표시합니다. 꺾은선은 3개년을 보여줍니다.
- 그래프 요약은 금액의 합계가 아니라 대표 5사 각 기업의 변동률을 저장된 현재 시가총액 비중으로 가중평균한 값입니다. KRX 공식 구성 비중이나 산업 전체 합계가 아닙니다. 과거 연도에도 같은 비중을 사용합니다. 결측 기업이 있으면 평균을 계산하지 않습니다. 주성엔지니어링의 현금 유형자산 취득 합계가 현재 계정 매핑에서 확인되지 않아 해당 변동률은 표시되지 않습니다.
- 결측·연결/별도 기준 변경 구간은 이어 그리지 않습니다. 전년 값이 0 이하이면 변화율을 계산하지 않습니다.
- 워드클라우드 아래 AI 산업 인사이트는 최대 3문장, 400자의 한 문단입니다. 기회·위험·3년 변화·앞으로 확인할 조건은 이 문단에 통합하고 별도 카드를 표시하지 않습니다. 기업 진입 카드는 인사이트 바로 아래에 배치합니다. 비교표와 기업 재무표는 유지합니다.
- 문장별 작은 각주를 누르면 원문 앞뒤 문단과 정확히 인용한 부분의 강조 표시를 확인합니다. 원문은 중앙 `source/blocks/*.jsonl`에서 읽으며 문단 ID와 문자 위치, 실제 인용 문자열을 검증합니다. 임의 파일 경로로 접근할 수 없습니다. DART 전체 원문 링크도 제공합니다.
- 2차 구상의 취지에 따라 인사이트는 수치 나열보다 사업의 의미를 쉽게 설명합니다. 계획과 실행·성과, 표본 기업과 산업 전체, 전사 재무와 반도체 부문을 구분합니다. 반복 서술이나 단어 빈도를 새 사건으로 해석하지 않습니다. 전후 비교는 서로 다른 기간의 공시 근거를 함께 사용하도록 프롬프트에 지정했습니다. 문자열 검증은 출처 위치를 확인하는 것으로 해석의 타당성까지 자동 보증하지는 않습니다.

## 인사이트만 생성하기

전체 보고서를 다시 분석하지 않고 인사이트만 생성할 수 있습니다.

```powershell
$env:LLM_PROVIDER = 'gemini'
python -X utf8 -m snapdart.insights
# 캐시를 사용하지 않고 다시 생성
python -X utf8 -m snapdart.insights --force
```

현재 최신 연도는 Gemini로 생성하며 이전 연도는 공시 직접 발췌임을 화면에 표시합니다. 최신 연도의 분기·반기·사업보고서 근거와 앞선 2개년 근거, Python 재무 계산, 기존 해석을 함께 제공합니다. 기존 해석은 인용 근거로 인정하지 않습니다. 코드는 검색 청크에서 최대 280자의 원문 발췌를 만들고 문자 위치를 고정합니다. Gemini는 인용문을 다시 작성하지 않고 문장별 출처 ID만 선택합니다. 존재하는 ID인지 검증한 뒤 고정 원문과 위치를 저장합니다. 요청은 순차 실행하며 기존 토큰 계산·사용량 예산·대기·재시도를 사용합니다. 실패하면 기존 화면 보고서를 보존하고 완료된 요청의 캐시는 다음 실행에서 재사용합니다. `--offline`은 외부 호출 없이 발췌 화면을 생성합니다.

## 전일 종가와 KRX API

BOOTCAMP_MINI/.env에 아래 항목을 추가합니다. 코드에 실제 키를 적지 않습니다.

```dotenv
KRX_API=발급받은_인증키
```

인증키뿐 아니라 **KRX 시리즈 일별시세정보** 서비스의 사용 승인도 필요합니다. FinanceDataReader 0.9.202에는 KRX OPEN API 인증키 연동 기능이 없습니다. 따라서 기업 시세는 FinanceDataReader의 NAVER 조회, 지수는 공식 KRX API 직접 호출로 연결합니다. CSV나 ETF를 사용하지 않습니다.

```powershell
cd C:\Users\LSH\Downloads\Code\BOOTCAMP_MINI_PROTO
..\BOOTCAMP\.venv\Scripts\python.exe -X utf8 app.py --port 8502
# 시세만 갱신 (공시와 LLM 분석은 실행하지 않음)
..\BOOTCAMP\.venv\Scripts\python.exe -X utf8 -m snapdart.market --prices-only
# 이미 저장된 자료로만 서버 실행
..\BOOTCAMP\.venv\Scripts\python.exe -X utf8 app.py --no-market-refresh
```

서버를 실행할 때 자동으로 시세를 갱신합니다. 실행 중인 서버가 자정에 자동으로 다시 수집하지는 않습니다. 계속 켜 둘 경우 Windows 작업 스케줄러에서 위 `--prices-only` 명령을 매일 아침 실행하면 됩니다.

한국시간 실행일 이전 마지막 거래일 종가를 표시합니다. 금요일 실행이면 목요일 종가, 월요일 실행이면 휴장이 없었던 금요일 종가입니다. 표시 등락률은 그 종가와 한 거래일 더 이전의 종가를 비교합니다. 당일 행은 공급자가 반환해도 제외하며, 휴일에는 가장 최근 거래일을 사용하고 기준일을 화면에 명시합니다. 첫 수집은 최근 3년 지수 시계열을 날짜별로 가져오므로 시간이 걸릴 수 있습니다. 이후 `data/krx_api/index_days.json` 캐시를 재사용하고 최근 날짜를 재조회해 미게시·정정에 대비합니다. 기업 그래프는 기존처럼 최근 65개 일별 종가를 유지합니다. 지수는 실제 포인트 그대로 사용합니다.

API의 `IDX_NM`이 정확히 KRX 반도체인 자료만 선택하고 날짜·종가를 검증합니다. 공개 샘플에는 반도체 항목이 없었으며, 승인된 실제 키로 이 항목이 제공되는지는 아직 확인하지 못했습니다. 실제 응답에도 없으면 명확한 오류를 표시하고 KRX 300·ETF·합성 지수로 대체하지 않습니다. 인증 오류·네트워크 오류가 발생하면 기존 자료와 완료된 날짜 캐시를 보존합니다. 실패한 자료는 갱신 실패 표시와 실제 기준일로 구분합니다. 키와 서버의 원시 오류 메시지는 브라우저·로그에 노출하지 않습니다.

공식 참고: [KRX API 서비스 명세](https://openapi.krx.co.kr/contents/OPP/USES/service/OPPUSES001_S2.cmd?BO_ID=SsgXTEspyJESKvyXZtCU), [승인 절차](https://openapi.krx.co.kr/contents/OPP/INFO/OPPINFO003.jsp).

## 선택 실행하는 분석과 검색

화면 실행이나 기본 재생성은 Gemini를 호출하지 않습니다. AI 해석이 필요할 때만 명시적으로 실행합니다. 기본 화면도 공시 발췌와 계산 자료로 작동합니다.

```powershell
$env:LLM_PROVIDER = 'gemini'
python -X utf8 -m snapdart.analyze --llm
# 기존 캐시를 건너뛰어 새로 생성
python -X utf8 -m snapdart.analyze --refresh-llm
```

기업·분기별 입력 선택 → 묶음 요약 → 연간 통합 → 기업/산업 보고서 순서입니다. LLM 실행 시 기본 정성 검색은 Qdrant입니다. BGE-M3로 사업 개요·수요/위험·투자·제품/실행의 네 질의를 한 번 임베딩하고 기업·기간·본문·사업의 내용 필터로 기간당 최대 20개 청크를 검색합니다. 원문 수치 CSV의 관련 출현 기록과 재무 JSON에서 Python이 계산한 연간 수치를 함께 제공합니다. 모델이 직접 파일이나 DB를 여는 방식이 아니라 코드가 필요한 근거를 가져와 프롬프트에 넣는 방식입니다.

Qdrant 또는 로컬 임베딩 모델 연결에 실패하면 동일 처리 결과의 파일 청크를 주제별로 선택하고 `file-fallback` 상태를 분석 입력/캐시에 기록합니다. `$env:SNAPDART_RETRIEVAL='file'`로 파일 검색을 명시할 수 있으며 기본값은 `qdrant`입니다. `QDRANT_URL` 기본값은 `http://127.0.0.1:6333`입니다. 모델/컬렉션은 중앙 manifest에 기록된 것을 사용하며 새 컬렉션을 만들거나 기존 벡터를 변경하지 않습니다.

기존 토큰 예산·대기·재시도·근거 ID/연도 검증을 유지하며 3개년으로 설정했습니다. 근거는 새로 자른 XML이 아니라 중앙 파이프라인의 청크입니다. 완료 전 오류가 나면 기존 `reports.json`을 보존합니다. 캐시·오류 기록은 프로토타입 `data/llm`에 저장합니다. Intel GPU 실행은 기존 BOOTCAMP 임베딩 환경을 사용하고, GPU가 없는 환경에서는 같은 모델을 CPU로 사용합니다.

Qdrant 검색도 중앙 파이프라인을 재사용합니다. 기존 임베딩 환경과 실행 중인 Qdrant가 필요합니다.

```powershell

```

## 그래프에서 매출과 공시 확인

범례 기업명에 마우스를 올리거나 키보드로 초점을 맞추면 최근 3개년 전사 매출액과 공시 버튼이 나타납니다. 작은 창으로 마우스를 이동하거나 창의 버튼에 초점을 둔 동안에도 표시됩니다. 모바일에서는 범례와 그래프 지점을 누릅니다. 지점에서는 해당 연도 매출액·매출의 전년 대비 변동률을 표시하고, 다른 지표 그래프이면 해당 지표의 금액·변동률도 함께 표시합니다. 연결·별도 기준 변경이나 전년 값이 0 이하인 변동률은 확인 불가로 유지합니다.

공시 버튼은 재무 API의 매출액과 원문 XML 재무 표의 당기 금액 셀을 원·천 원·백만 원·억 원 단위로 대조한 뒤 해당 셀을 강조한 원문 위치를 보여줍니다. 문서 접수번호·문단 ID·XML 위치를 유지하고 DART 전체 원문 링크도 제공합니다. 일치하는 위치를 찾지 못하면 임의 위치로 연결하지 않습니다. 선은 실제 값 사이를 직선으로 연결하여 곡선 보간으로 값이 과장되지 않도록 하며, 범례에서 선택한 기업의 선을 강조하고 앞으로 가져옵니다.


범례 팝업은 해당 범례 옆에 표시합니다. 창으로 이동하는 중 다른 범례를 잠시 지나가도 전환하지 않으며, 다른 범례에 잠시 머물렀을 때만 기업을 바꿉니다. 원문 표는 중앙 `source/tables/문서ID.jsonl`에 보존된 전체 행·열과 rowspan/colspan을 그대로 복원하고 대상 금액 셀을 강조합니다. 표 안에서 스크롤하여 나머지 행도 확인할 수 있습니다. 원문 XML의 글꼴·장식은 웹 가독성에 맞춰 표시하지만 표의 내용과 병합 구조는 유지합니다.

그래프 디자인은 [GOV.UK 차트 가이드](https://brand.design-system.service.gov.uk/colour/charts/)의 색상·보조선 원칙과 [Highcharts 팝업 동작 설명](https://api.highcharts.com/highcharts/tooltip.stickOnContact)을 참고했습니다. 별도의 차트 라이브러리를 추가하지 않고 기존 SVG 구현을 유지합니다.

### 핵심 지표 그래프의 자동 눈금과 범례

지표마다 화면에 표시되는 5개 기업의 3개년 전년 대비 변동률을 모아 모집단 표준편차를 계산합니다. 누락값은 제외하며 0으로 채우지 않습니다. 표준편차가 **300%p 이상**이면 대칭 로그 눈금으로 전환하고, 그 미만이면 일반 눈금을 사용합니다. 기준은 `web/app.js`의 `TREND_LOG_STD_THRESHOLD`에서 변경할 수 있습니다. 이 값은 시각화를 위한 초기 기준이며 투자 판단 기준은 아닙니다.

대칭 로그 변환은 `sign(v) * log(1 + abs(v) / 10)`입니다. 음수와 0을 보존하고 큰 변동률 때문에 작은 변동이 눌리는 현상을 줄입니다. Y축 범위는 0%를 포함하며 눈금·팝업·대표 수치는 원래 변동률로 표시합니다. 로그 눈금에서 화면상 거리나 선 기울기를 변동률의 산술 차이로 읽으면 안 됩니다. 변동률 산식과 원본 재무 데이터는 바꾸지 않았습니다. 표준편차의 단위 %p는 변동률 간 차이의 단위입니다.

범례를 선택하면 같은 기업의 선과 점을 강조하고 다른 그래프로 이동할 때 이전 강조를 해제합니다. 범례 상세 창은 가능한 한 그래프 바깥에 배치합니다. 전년 값이 0 이하이거나 재무 기준이 다르거나 값이 누락된 경우 기존 원칙대로 해당 점을 제외하며, 비교 자료가 없는 기업은 팝업에 그래프 미표시 안내를 표시합니다. 매출액 팝업이 표시되는 것과 다른 핵심 지표의 변동률이 존재하는 것은 별개입니다.

눈금 구현 참고: https://d3js.org/d3-scale/symlog (별도 라이브러리 추가 없이 구현).


### 모바일 보고서 화면과 지표 비교 (2026-10-02)

서비스 화면은 9:18 비율의 앱 화면 안에서 세로로 스크롤합니다. 기업 화면의 사이드바 대신 기업명 오른쪽의 산업 지도 링크와 기업 선택 드롭다운을 사용합니다.

지표 범례와 점의 상세 창은 해당 카드의 매출·영업이익·설비투자·영업현금흐름 금액 및 변동률을 표시합니다. 원문 버튼도 해당 지표의 검증된 원문 표 셀을 찾습니다. 정확한 셀을 확인할 수 없으면 다른 수치로 대체하지 않습니다. 로그 전환 표준편차 기준은 300%p이며, Y축은 최소·최대와 0을 포함한 범위에 변환 눈금 기준 9% 여유를 둡니다. 일반 눈금에서는 원 수치, 로그에서는 변환 수치 기준 여유입니다.
