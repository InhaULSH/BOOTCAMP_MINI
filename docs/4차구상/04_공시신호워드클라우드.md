# 공시 신호 워드클라우드

확인 기준일: 2026-10-08. [문서 목록](README.md)

## 구현 의도

긴 공시에서 제품·수요·생산·투자와 관련된 사업 용어를 먼저 보여주고, 단어를 선택하면 쉬운 설명과 공시 근거로 이어지도록 한다. 단어의 선정은 코드가 계산하고 설명은 Gemini가 생성한다. 단어가 자주 나왔다는 사실을 실제 사업 성과로 해석하지 않는다.

## 대상 공시와 단어 추출

산업 워드클라우드는 현재 지수 구성기업 가운데 DB의 비중 순으로 고른 최대 5개 기업을 사용한다. 비중이 없으면 기업 코드 순으로 결정되며, 해당 보고서의 분석 기업에도 포함되어야 한다. 재무 그래프의 분석 대상 전체와 반드시 같은 범위는 아니다. 기업 워드클라우드는 그 기업의 공시를 사용한다.

분석 기간은 보고서의 전체 선택 연도다. 기본 보고서가 DB 전체 연도를 사용하면 워드클라우드도 같은 연도 범위를 사용한다. 점수 엔진의 독립 실행 기본값 `(2023, 2024, 2025)`를 서비스의 고정 기간으로 해석하면 안 된다. 최신 연도 화면에 전체 기간을 비교한 단어가 표시된다.

Q1·H1·Q3·FY의 검색 가능한 청크 중 `II. 사업의 내용`, `IV. 이사의 경영진단 및 분석의견` 등 코드에 허용된 섹션·연구개발 소제목을 사용한다. 청크 ID를 중복 제거하고 Kiwi 형태소 분석과 산업별 별칭·복합어·기술어 규칙으로 후보를 추출한다. 회사명, 표의 단위, 문서 작성 표현, 일반적인 추상어 등은 필터링한다.

한 청크에서 단어가 여러 번 등장해도 그 단어의 청크 언급 횟수는 1회다. 예를 들어 한 문단에 HBM이 8번 반복되더라도 한 청크면 1개로 센다. 다른 청크 4개에 있으면 4개로 센다. 따라서 화면의 count는 일반 단어 빈도가 아니라 단어가 포함된 중복 제거 청크 수다.

## 후보 조건과 계산

최신 연도에서 최소 2개 청크에 등장해야 한다. 산업 단어는 최소 2개 기업에서 확인되어야 하고 기업 화면은 1개 기업 조건을 사용한다. 필터를 통과한 후보끼리 현재 언급 비율과 변화의 상대 순위를 구한다.

| 항목 | 계산 의도와 현재 방식 |
| --- | --- |
| 연도별 언급 비율 | 단어를 포함한 청크 수 ÷ 해당 연도의 전체 대상 청크 수 |
| 현재 점수 | 최신 연도 언급 비율의 후보 내 백분위 점수 |
| 변화값 | 인접 연도 언급 비율 차이를 가중평균; 최근 구간의 비중이 더 큼 |
| 변화 점수 | 위 변화값의 후보 내 백분위 점수 |
| 확산 점수 | 최신 연도 언급 기업 수 ÷ 대상 기업 수 × 100 |
| 기업 집중 감점 | 한 기업의 언급 점유율이 50%를 넘을 때 증가, 최대 15점; 기업 화면은 0 |
| 일반 경영 감점 | 규칙에 해당하는 일반 경영 단어에 2점 |

최종 점수는 `현재 점수 × 0.50 + 변화 점수 × 0.30 + 확산 점수 × 0.20 - 기업 집중 감점 - 일반 경영 감점`이다. 최종 점수 상위 최대 12개를 표시한다. 3개년이면 이전 변화 구간 0.4, 최근 구간 0.6을 사용한다. 기간이 길어지면 모든 인접 구간을 포함하고 0.4에서 0.6까지의 가중치를 합이 1이 되도록 정규화한다. 1개년이면 변화값은 0이다.

기업 집중 감점은 `min(15, max(0, (최대 기업 점유율 - 0.5) × 30))`이다. 상승 강조는 변화 점수≥90이면서 실제 변화값이 양수인 경우 적용한다. 단순히 최종 점수가 높다는 이유로 상승 신호를 붙이지 않는다.

산업 선정 표본 또는 개별 기업에서 대상 연도의 공시 청크가 없는 경우 빈 결과와 누락 연도를 기록한다. 청크가 없는 연도를 단어가 0회 등장한 정상 관측으로 취급하지 않는다.

## 단어 크기와 설명

순위를 정하는 `final_signal_score`와 화면 크기의 `display_weight`는 구분한다. 현재 화면은 계산된 시각화 가중치를 받아 단어 크기를 정하고, 상승 신호를 별도로 강조한다. 사업 용어의 설명과 공시 맥락은 [인사이트 생성](03_인사이트생성과프롬프트.md) 경로로 생성된다. 단어 점수, 검색 유사도, 설명문의 근거 점수는 서로 다른 값이다.

신규 산업은 DB 목록에 추가할 수 있지만 산업별 별칭·전문어·문맥 조건은 `SectorVocabulary`를 검토해야 한다. 등록되지 않은 산업은 일반 어휘 규칙을 사용하므로 도메인별 추출 품질이 자동 보장되지는 않는다.
