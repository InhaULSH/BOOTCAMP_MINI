# 10. 현재 코드 변경점과 적용 범위

확인 기준: 2026-10-12의 로컬·배포 코드. DB나 원격 서버가 이 파일과 같은 상태로 배포되었다는 뜻은 아니다. 과거 제안과 현재 구현을 구분하여 정리한다.

## 먼저 알아둘 현재 기준

지원 프롬프트는 **new·new2·old**, 기본값은 new다. 화면 디자인의 old/new 선택과는 별개의 설정이다. 생성 응답 검증은 기본 **mvp**, 선택적으로 strict다. 따라서 프롬프트에 수치·점수·문장 수 규칙이 있어도 기본 코드 검사가 이를 모두 실패 조건으로 강제하는 것은 아니다.

최근 변경은 원격 DB를 바꾸는 작업보다 기존 자료를 안전하게 읽고 화면과 설명에 연결하는 작업에 집중되어 있다. 그래프의 수치 검증, 생성된 설명의 승인, 원문 위치 표시는 서로 다른 단계다.

## 프롬프트 정리에서 삭제한 범위

new3 전용 소스는 다음 6개다.

- `snapdart/data_access/prompts_new3.py`
- `dart_remote/citation_selection_new3.py`
- `dart_remote/new3_definition.py`
- `deploy/cloudapp/prompts_new3.py`
- `deploy/dart_remote/citation_selection_new3.py`
- `deploy/dart_remote/new3_definition.py`

전용 `tests/test_new3_insights.py`와 해당 Python 캐시도 제거했다. CLI·환경설정·요청별 선택·보고서 발행에서 종료한 버전을 허용하지 않는다. new3만 사용하던 한 종류 근거 허용 및 2-4문장 분기도 공통 파이프라인에서 제거했다.

new·new2·old 지침 본문과 공통 mvp/strict 검증·재무 준비·그래프·워드클라우드는 제거 대상이 아니다. 기존 unsupported 버전의 저장 보고서를 new로 오인하지 않도록 분류를 보완했다. 기존 분석 JSON·원격 DB를 지우거나 원격 서버를 변경하지 않는다. `docs/DART_BIG_IN_final_prompt.txt`는 전달받은 원본 참고 자료로 남지만 실행 코드가 읽지 않는다.

## 제안했지만 아직 구현되지 않은 사항

직전 대화의 100자 미만 또는 공통 근거 부족 인사이트에 대해 산업·기업 탐색용 고정 문구를 표시하고 카드 제목을 바꾸는 기능은 아직 없다. 현재는 예외 또는 빈 설명의 부족 이유를 표시한다. AI 설명 길이만으로 대체하거나 산업 공통성을 새로 판정하지 않는다.

new2 프롬프트는 적격 재무·공시 정보의 종합을 요구한다. 그러나 기본 mvp에서 두 종류 근거 균형을 코드의 승인 실패 조건으로 사용하지 않는다. **의도한 출력과 강제 검증의 범위를 구별해야 한다.** strict에서는 해당 조건과 수치 비교를 검사한다.

## 변경을 적용할 때 필요한 작업

문서와 지원 버전 제거 자체로 기존 new·new2·old 결과를 다시 생성하거나 DB를 재적재할 필요는 없다. 다만 새 프롬프트·검증 모드의 설명이 필요하면 해당 버전으로 분석해야 한다. 워드클라우드의 새 단어 설명도 필요하면 재분석한다. 그래프 최신 분기·브라우저 코드 변경은 웹 리소스 갱신으로 적용한다.

배포는 수정 deploy 전송 → 이미지 재빌드 → 필요한 분석 → 웹 컨테이너 재생성 순서다. 과거 코드로 이미 실행 중인 서버가 로컬 수정만으로 바뀌지는 않는다.

## 검증과 발표 자료

남은 버전의 프로필·단일 호출·각주·성공 보고서 선택, strict 부정 사례, mvp 경고·실패 격리와 최신 분기·로컬/배포 일치는 별도 테스트로 확인한다. [08](08_XML기반오프라인통합검증.md)은 실제 DB·Gemini 없이 확인한 범위를 설명한다. 실서비스 품질이나 서버 정상 배포를 테스트 숫자만으로 주장하지 않는다.

전체 동작을 발표할 때는 [발표용 서비스 파이프라인](../프로젝트_발표용_서비스_파이프라인.md)을 먼저 읽고, 현재 승인 모드와 구현 한계는 이 문서와 [03](03_인사이트생성과프롬프트.md)을 함께 확인한다.


이번 작업의 확인 결과: 관련 Python 회귀 테스트 159개, UI·단일 누락 그래프·워드클라우드 배치의 JavaScript 테스트 3개가 통과했다. 남은 new2·old 프롬프트와 공통 검증·재무·생성·화면 파일 10개의 작업 전후 해시가 같음을 확인했다. 실행 소스에는 종료 버전 선택·import·전용 분기가 남지 않았으며 해당 전용 바이트코드도 제거했다. 종료 버전이 거부되는지 검사하는 회귀 테스트와 삭제 이력 문서에는 이름이 남는다. 사용자 원본 참고 자료와 기존 보고서, 작업 전부터 존재하던 임시 폴더는 보존했다. 이번 테스트의 빈 임시 폴더 25개는 정리했다.
