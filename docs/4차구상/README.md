# DART BIG:IN 현재 구현 안내

확인 기준일: 2026-10-08. 이 문서 묶음은 현재 로컬 코드와 `deploy/`의 배포 코드를 기준으로 작성했다. 실제 DB에 등록된 기업·연도와 API의 사용 한도는 운영 중 바뀔 수 있으므로 고정 숫자로 단정하지 않는다.

서비스는 산업과 기업의 사업 흐름을 공시와 재무정보로 설명한다. 원격 MySQL에서 표준화된 수치와 공시 청크·벡터를 읽고, 로컬 BGE-M3 검색으로 관련 문구를 찾는다. 분석 명령을 실행하면 Gemini가 인사이트를 생성하고 코드가 각주를 검증한다. 브라우저는 저장된 보고서와 시세를 표시한다. 공시 원천 수집·청킹·전체 임베딩·DB 적재는 현재 서비스 실행 과정에 포함되지 않는다.
